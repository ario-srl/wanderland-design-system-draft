Favicon Wanderland: il simbolo a colori su fondo trasparente, ritagliato e centrato in un quadrato, in sette dimensioni.

- `favicon-16`, `32`, `48`, `64`: per il tag `link rel="icon"` nei browser desktop.
- `favicon-180`: per `apple-touch-icon`.
- `favicon-192` e `favicon-512`: per il manifest web app.
- Il fondo è trasparente: sulle schede scure del browser il verde del simbolo ha poco contrasto. Non esiste un file `.ico`.
- I file sono immagini: si mostrano solo con `<img>`.
